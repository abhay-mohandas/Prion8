Note: All memory related operations are in Little Endian format, (Higher bits -> Lower bits)
The lowest address holds the least significant byte, which goes in the low register. 
The stack grows down and SP points at the last item pushed, 2-byte pushes (CALL, RCALL, PUSHM) do SP = SP - 2, then [SP] = low byte and [SP+1] = high byte.
All instructions not listed in the flag table leave flags unchanged

Rules:
 -Sticky ZF: only ADC and SBC use the old ZF. Always start a multi-byte chain with ADD or SUB (ADC/SBC alone continue a chain), and the final ZF is a correct zero test for the whole value.
 -Shifts: count 0 changes nothing, including flags. For SHL and SHR, a count of 8 or more gives 0 (CF is the last bit out for exactly 8, and 0 beyond that). ASR with a count of 8 or more gives 0x00 or 0xFF by the sign bit, and CF = the sign bit. SHR is logical, and ASR is the arithmetic one.
 -INC/DEC: CF is left alone, so a counter can step through a multi-byte add without losing the carry. They don’t take part in sticky ZF.
 -BCPY and BS/BC: the bit number comes from the low 3 bits of RB.
 -DIV by zero: raises a fault, and registers and flags stay unchanged.
 -SFB/CFB: the mask covers the five defined bits (CF=0x01, ZF=0x02, NF=0x04, OF=0x08, IF=0x10), and other bits are ignored. In user mode, IF mask raises a privilege fault, so user code can’t change IF.
 -MGS to FLAGS: the same masking applies(raises a privilege fault in user mode).
 -Interrupts and faults: both saves IP, FLAGS and CTRL, and ERET restores both.
 -Reset: all flags are 0.
